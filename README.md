# 番茄闹钟 🍅

一个桌面番茄工作法计时器，**单文件、无第三方依赖**（仅用系统自带 tkinter）。

## 功能

- 25 分钟工作 → 5 分钟短休息，每 4 个番茄 → 15 分钟长休息（时长均可改）
- 圆形倒计时进度环 + 大字时间，颜色随阶段变化（工作红 / 短休绿 / 长休蓝）
- 开始 / 暂停、重置、跳过
- 到点响铃（三音提示）+ 窗口置顶闪烁 + 标题栏提醒
- 可选「自动开始下一阶段」「置顶」
- 设置自动保存到同目录 `pomodoro_config.json`（首次运行后生成）

## 运行

- Windows 直接双击 `番茄闹钟.pyw`（无黑色控制台窗口）
- 或命令行：`pythonw 番茄闹钟.pyw`

## 打包成独立 exe（可选）

```bash
pip install pyinstaller
pyinstaller -F -w 番茄闹钟.pyw
```
